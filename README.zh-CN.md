# Paper7 屏幕校色

| **简体中文** | [English](README.en.md) |
|:---:|:---:|

Paper7 屏幕校色是一款 Android 屏幕色彩调节应用，主要面向 Paper7。本软件完全由 AI 开发，相关资源可在[科技玩家](https://www.kejiwanjia.net/)网站查看。

## 功能

- 调节对比度、饱和度、Gamma、图像亮度、色相及红、绿、蓝通道。
- 使用悬浮窗在其他应用上方实时预览和调整屏幕效果。
- 从主界面或悬浮窗应用推荐设置；推荐设置中的饱和度使用系统原生索引 `4`。
- 提供 HAL 校准实验页，供用户尝试设备上的备用调节通道。该页面当前尚未验证跑通，写入被接口接受不代表画面效果已生效。
- 主界面和悬浮窗会同步显示已调整的参数。

## 使用要求

- 需要 Root 权限。请在 Root 管理器中允许 `com.paper7.displaytuner` 获取超级用户权限。
- 使用悬浮窗需要授予“显示在其他应用上层”权限。
- 主要面向 Paper7；其他设备和固件版本未经验证。

## 风险提示

本软件通过 Root 权限调用设备显示控制接口。Root 操作和屏幕调节可能影响设备运行或显示效果，请自行评估并承担风险。本软件仅供学习和个人使用，不提供任何担保。
